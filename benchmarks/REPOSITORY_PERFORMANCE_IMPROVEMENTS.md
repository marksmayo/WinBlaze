Targets sharing code or a workload are not independent measured wins. 150 additional candidates remain unqualified; no safe-savings claim is made for them.

## Ranking and estimates

Qualified changes first, ordered by expected avoided volume-scale memory/work and feature-workload exposure. This is engineering priority, not a measured universal savings order. Shared implementation sites are explicitly separate targets, not independent additive wins. Lower entries are not claimed safe without profiling.

Across different workloads, a universal numeric speed ranking is not justified. Entries without controlled measurements retain qualitative bounds rather than fabricated milliseconds. Existing optimizations are excluded. The table ranks implementation priorities; estimates overlap and must not be added.
