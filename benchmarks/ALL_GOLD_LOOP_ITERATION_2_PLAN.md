## Static audit during the rerun (no competing timing or builds)

- Rank 11: current export.rs streams quoted parent paths and names directly into the writer. It does not construct per-row path/escaping Strings. Existing public CSV export allocation tests already cover this; adding path scratch would introduce storage rather than remove it. Reject that proposed change unless a different measured allocation is found.
- Rank 14: ConcurrentAllocationTracker already uses 64 independent identity shards. Do not implement another generic sharding change or count the existing implementation as a new improvement. A further change needs actual contention evidence.
- Rank 6: each pipeline flush transfers a Vec through mpsc; the native consumer consumes and frees that vector. A bounded recycling channel could retain empty vectors for later producers, but must preserve current channel APIs, full event ordering, receiver-drop cancellation and a fixed memory bound. Public allocation red/green evidence is required before adoption.
- Ranks 22/23: existing traced metadata-provider activations were after first idle on an older binary. They cannot support claims about the three startup medal deficits. Obtain fresh phase/module evidence for the current executable after this complete measurement batch; do not move more work past first idle just to improve the proxy.

Additional source/build evidence: rank 9 preferred directory enumeration already retains one 64 KiB scratch buffer per thread (directory_metadata.rs DIRECTORY_BUFFER), with the public sequential reuse budget test green. Rank 21 snapshot file/directory serialization already reuses one scratch vector and makes one write_all per record into a bounded BufWriter. Do not count either existing mechanism as new work. The release CL command log contains Windows ML's lazy initializer but no bootstrap auto-initializer source/macro; a duplicate-bootstrap optimization is currently unsupported. Older phase diagnostics show application scan/export taking much less than process wall time; refresh diagnostic-only phase evidence on the current binary after the complete rerun before attributing tiny/dense variability to application allocations.
